04 / 填进 ST-iPhonie

在小手机的「引擎 → 自己的接口」中填写。不要填进原来的 Fish API Key 卡片。

请求方式 POST · 回答是 音频本身 · 角色音色先填 default

手机上的 127.0.0.1 指向手机本身。局域网访问需在适配器上启用 BRIDGE_HOST=0.0.0.0，把请求地址改为电脑 IP；仍需正确的桥接密钥。HTTPS 酒馆建议经自己的酒馆服务端代理连接。


本页不收集聊天内容或账号令牌。生成结果仅在进程内缓存；关闭进程会清空缓存与待查询任务。详见 README 的验证边界。
